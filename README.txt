# PoseVault Photo Pose Website

Open `index.html` in a browser to preview the website.

## Customize
- Add more images to `images/`.
- Edit the pose data inside `index.html` to add/change descriptions.
- Change the contact email in the `mailto:` links if needed.

## Free hosting
You can publish this static website with GitHub Pages, Netlify, or Cloudflare Pages.
